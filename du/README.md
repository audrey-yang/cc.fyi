# `du`

Following [Coding Challenge #124 - Du](https://codingchallenges.substack.com/p/coding-challenge-124-du).

## How to run

Run `make ccdu` to compile the executable run `./ccdu`. Refer to `du` for usage.

## Dependencies

This implementation depends on [uthash](https://troydhanson.github.io/uthash/userguide.html).
